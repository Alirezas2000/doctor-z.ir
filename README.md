# Doctor-Z.ir

پروژه کامل React + Vite + Tailwind CSS 4.

## نصب و اجرا

```bash
npm install
npm run dev
```

## ساخت

```bash
npm run build
```

لوگوی اصلی را در `public/logo.png` قرار دهید؛ تصویر اصلی در فایل‌های دریافتی موجود نبود.

مدیریت: `/admin` (نام کاربری `admin`، رمز `Admin` صرفاً برای نسخه نمایشی).

داده‌ها در localStorage همین مرورگر ذخیره می‌شوند؛ اعلان‌ها پیامک یا Push واقعی نیستند.

برای GitHub Pages مقدار `GITHUB_PAGES=true` هنگام build استفاده شود.
